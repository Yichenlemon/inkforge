## 0. 本轮全部新增汇总

### 0.1 Bug 定位：编辑默认值不生效
- **现状**（`useDoc.ts:86-110` `newDoc`）：仅对**第一个** paragraph/heading 注入 `defaultFontSize / defaultLineHeight / defaultFont / defaultAuthor`。
- **后果**：① 模板初始化第 2..N 块不应用默认；② `insertBlocks / addBlock / setTheme / 导入` 路径**完全不读默认**；③ `defaultAuthor` 只写到 `meta.author`。
- **修法**：
  1. `shared/types.ts` 新增纯函数 `applyBlockDefaults(block: Block, s: EditorSettings): Block`（仅当块**未显式设置**该字段时填默认，不破坏模板）。覆盖：fontSize / lineHeight / fontFamily / fontWeight / letterSpacing / color / textAlign / justify。
  2. `useDoc` 抽 `withDefaults = (blocks) => blocks.map(b => applyBlockDefaults(b, useUI.getState()))`，统一用于：`newDoc`（替换"只改 i===0"）、`insertBlocks / addBlock / replaceBlocks`（commit 后立刻套）、`setTheme`（整篇补缺）、`loadFromServer / 导入`（按 `applyDocDefaultsOnOpen` 开关）。
  3. 设置面板加 **"将默认值应用到当前打开文档"** 按钮（二次确认 + 自动备份快照）。
  4. 单元测试覆盖：模板已设→不覆盖；未设→用默认；heading/quote/paragraph/list/callout/card 对字号/行高生效；frame 子块不递归。

## 1. 设计目标与原则
1. **单一事实源**：所有"打开文档 / 最近 / 素材 / 片段 / 模板 / 回收站"只存于 `useFileStore`；首页、菜单、Tab、飞出、文件管理器全读它。
2. **动作注册表 ActionRegistry**：所有动作与链接集中声明一次，任何 UI 只调 `REGISTRY[id].run(item)`，新增动作只改一处。
3. **模块自包含**：新建 `src/filemgr/`，对外仅暴露 `useFileStore / useFileActions / openFileManager`；其余页面只 import 它。
4. **可插拔 facet**：文档/图片/SVG/Lottie/片段/模板/回收站共用一套列表/网格/预览/右键框架。
5. **不破坏现有**：旧 API 与首页外观保留，新模块增量叠加，稳定后逐步替换。

## 2. 现状诊断（为何"残缺、不成模块"）
- 文档逻辑散在 `HomePage / MenuBar / App / useDoc / useUI` 5 处，互相直接调用。
- 素材散在 `assets / snippets / templates / 在线库` 4 处无统一入口。
- 历史/版本与文档管理割裂；删除硬删无回收站、无反向链接；复制非原子。
- **右下角"编辑/预览/源码"悬浮条**：源码全文 grep（`Canvas/Preview/ui.tsx`）均无 `viewMode` 引用，与"半透明底栏"同源，疑 HMR/旧 bundle/CSS 注入——属**冗余功能，必须移除**（§14.1）。

## 4. 统一数据模型 `FileItem`
```ts
type FileKind = 'doc' | 'image' | 'svg' | 'lottie' | 'snippet' | 'template'
interface FileItem {
  kind: FileKind; id: string; name: string
  thumbnail?: string; mime?: string; size?: number
  tags?: string[]; category?: string; author?: string
  createdAt: number; updatedAt: number; lastOpenedAt?: number
  status: 'saved' | 'dirty' | 'saving' | 'error'
  deletedAt?: number; pinned?: boolean
  refs?: { docId: string; docTitle: string }[]   // 反向链接：谁在用
  meta?: Record<string, any>
}
```
各 facet 用 adapter 把 DB 行映射成 `FileItem`。

## 6. 动作与链接注册表 `ActionRegistry`（核心）
```ts
type FileActionId =
  | 'open' | 'open-new-tab' | 'open-readonly' | 'duplicate' | 'rename' | 'delete'
  | 'restore' | 'purge' | 'export-md' | 'export-html' | 'publish-draft'
  | 'copy-link' | 'copy-url' | 'download' | 'insert-into-doc' | 'add-tag'
  | 'pin' | 'unpin' | 'open-containing-folder' | 'used-in' | 'view-history' | 'restore-version'
  | 'preview' | 'batch-import' | 'batch-export' | 'batch-delete' | 'batch-tag'
  | 'convert-image' | 'optimize-svg' | 'regenerate-thumbnail' | 'move-to-folder'
  | 'check-duplicates' | 'merge-duplicates' | 'replace-asset-globally'
  | 'open-in-wechat-draft' | 'send-to-phone' | 'reveal-in-history'
  | 'insert-audio' | 'insert-video' | 'lock' | 'unlock' | 'toggle-lock'
const REGISTRY: Record<FileActionId, { label: string; icon: LucideIcon; appliesTo: FileKind[]; run: (item, ctx) => void | Promise<void> }>
```
`ctx` 提供 `activeDoc / useFileStore / useDoc / toast / openModal`。右键菜单/按钮/快捷键/拖拽落点全部查 `REGISTRY[id].run(item)`。新增动作只改这一处。

## 8. 文件管理增强（v2）

### 8.1 预览面板（必做）
- 图片：大图 + 元数据(分辨率/大小/格式/上传时间/tag/used-in) + "替换"。
- SVG：实时渲染 + 源码(折叠) + 动画时间轴 + "复制 SVG/复制 dataURL/导出 PNG"。
- Lottie：`<lottie-player>` 播放 + 帧时间轴 + 替换 JSON / 导出 GIF(v1.1) / MP4。
- 片段/模板：富文本预览 + "插入到文档(光标/文末/选区替换)" + "克隆为我的片段"。
- 文档：导出 HTML 纯样式快照 + 版本历史缩略图。
- 预览面板宽度可拖拽(280–600px)，记忆 localStorage。

### 8.2 批量导入/导出（必做）
- **导入**（顶部按钮 + 拖文件夹）：来源 = 本地多选 / 文件夹递归 / 远程 URL 列表 / 在线库勾选；按 MIME 自动归类（image→assets、svg→ingest、json+lottieProbe→lottie、md/html/docx→docs 每文件一篇）；**去重 sha256 三选一**（跳过/覆盖/改名）；底部进度 + 失败列表(重试/跳过)。
- **导出**（多选后工具条）：范围 = 选中/全部/多 facet；图片格式按设置项(JPEG/WebP/AVIF)；SVG→优化 SVG/PNG；Lottie→JSON/GIF；文档→HTML 拼 zip / Markdown 拼 zip；命名 `{title}-{yyyymmdd}-{index}`；直接下载 zip 或写入指定文件夹。

### 8.3 素材筛选（必做）
| 维度 | 可选项 |
|---|---|
| 类型 | 图片/SVG/Lottie/片段/模板(多选 chip) |
| 大小 | <50KB / 50–500KB / 0.5–2MB / 2–10MB / >10MB |
| 尺寸 | ≤480p / 720p / 1080p / 2K / 4K |
| 上传时间 | 今天/7天/30天/90天/今年/全部 |
| 用量 | 未使用/1处/2–5处/>5处(基于 used-in 反查) |
| 标签 | 多选 tag(AND/OR 切换) |
| 状态 | 有/无动画/公开/私有/已置顶/已软删 |

排序：最近活动/大小/宽×高/名称/上传时间/使用频率。筛选状态写 URL query 便于分享保留。

### 8.4 重复检测 & 全局替换
- "查找重复"：按 sha256 / pHash(图像) / 文本相似度(SVG/snippet) 找可合并项，确认后保留最新、其余移回收站。
- 右键"全局替换"：搜所有引用此 asset.id 的文档块，弹窗列引用点(缩略+文档名+跳转)，逐点确认替换。

## 11. 音频 / 视频插入（基于公众号官方约束）

### 11.1 公众号真实约束（来自官方文档）
- **音频**：文章内由微信私有标签 `<mpvoice name title src=MEDIA_ID>` 承载；素材须先传到**微信素材库(永久素材 type=voice)** 得 media_id。支持 mp3/wma/wav/amr/m4a；后台上传 ≤200M、时长≤2h；**API 永久素材 voice 仅 ≤2MB / ≤60s**（设计以 API 限制兜底）；标题≤30字、类型必填。
- **视频**：文章内由 `<mpvideo>` 承载。两种来源：① **腾讯视频 vid**（粘贴链接，最稳，带腾讯水印）；② **微信素材库上传**（需审核）。每篇图文**最多 3 个视频**；推荐 MP4(H.264+AAC)；时长<1h。
- **关键推论（兼容性 + 可靠性）**：InkForge 是"导出 HTML → 粘贴到公众号后台"的本地编辑器，音频/视频块导出时必须 emit 微信私有标签，而该标签要求 media 已在微信素材库。因此：
  - 音频/视频块 = **编辑器内本地预览 + 导出时 emit 私有标签 + 提示"导出前需在微信素材库上传并填 media_id / 腾讯视频 vid"**。
  - 不强制联网上传（保持离线可用）；"同步到公众号"路径（§13.3）作为可选自动上传。

### 11.2 新增 Block 类型
- `audio`：`{ src?, mediaId?, title, cover?, duration? }`；编辑器内 `<audio controls>` 本地预览。
- `video`：`{ src?, mediaId?, tencentVid?, title, poster? }`；编辑器内 `<video controls poster>` 预览；支持腾讯视频(填 vid)。
- 两者挂 `BlockBase`（继承 groupId/note/选中/拖拽）。

### 11.3 悬浮工具栏补全（插入入口）
现有富文本**气泡菜单(BubbleMenu)/悬浮工具栏**的"插入"分组**缺音频、视频**，新增两项：
- 「音频」→ `InsertAudioDialog`：本地选 mp3 → 填标题/分类/封面 → 生成 `audio` 块（含"填入微信 media_id"字段）。
- 「视频」→ `InsertVideoDialog`：三选项(本地 mp4 / 腾讯视频链接 / 素材库引用) → 生成 `video` 块。
- 两对话框复用 `Modal + useUI.openModal`，登记到 **ActionRegistry**（`insert-audio / insert-video`），右键/命令面板/拖入复用同一逻辑。
- 导出(`render.ts`)：`audio` → `<mpvoice name title src=MEDIA_ID>`（空则带占位注释 + 醒目警告）；`video` → 有 `tencentVid` 走 `<mpvideo>` 引用 vid，有 `mediaId` 走素材库，否则警告。

### 11.4 QQ音乐（"音乐"来源）—— Msg 6 补充
公众号文章里**声音分两类**，必须区分：
- **音频（上传）**：本地 mp3/wma/wav/amr/m4a → 素材库审核 → `<mpvoice>`。1 篇图文最多 **10 个本地音频**；标题≤64字；平台审核通过才可用。**可加标签**。
- **音乐（QQ音乐直连）**：编辑器 音频→**音乐** 选项卡内**搜索 QQ音乐曲库**一键插入，无需本地上传、自动带封面与元数据；**仅支持 QQ音乐曲库**（无版权歌曲不可见）；1 篇图文最多 **20 个音乐**；带 VIP 标则读者需 QQ音乐会员；**不可加标签**。

### 13.2 接替方案：右下角 = 画布缩放器 + 文件锁

#### 13.2.1 画布缩放器（Canvas Zoomer）
- 形态：右下角悬浮胶囊(高 28px)，左=当前比例、中=滑块(25–400%，步长5%，主刻度25/50/75/100/125/150/200/300)、右=⊕适配/⊖实际。
- 比例自定义：点数字弹迷你输入(支持 `50`/`75%`/`0.5`/`fit`)；滑块+输入双向绑定；预设下拉(手机/iPad/桌面/公众号头图/自定义)。
- 快捷键（入设置"快捷键"组，可改键）：`Ctrl/Cmd + =`(+10%) / `-`(-10%) / `0`(100%) / `1`(适配宽度) / `2`(适配整页) / `Ctrl+Wheel`(缩放) / `Alt`(按住临时缩放，松开回原)。
- **实时真实鸟瞰图（Bird's-eye Live Thumbnail）—— 本模块一等交互，必须强调**：
  - **悬停即现**：悬停滑块 200ms 弹真缩略图浮窗(宽 240px，固定于缩放器上方)。
  - **真渲染**：非 SVG 占位，把 `useCompiledPreview().html` 套当前主题 token 真编译，渲到 `<iframe>`，按悬停刻度 `transform: scale()` 缩放。
  - **★ 拖动 / 点击即调整画布位置（核心，默认开启的一等能力）**：
    - 浮窗内**半透明红色视口矩形**标出"当前可视区在整页中的位置"（基于 scrollTop/Left/可视区宽高/整页宽高）。
    - **拖动红矩形** → 画布实时 `scrollTo` 跟随，松手即停；
    - **点击浮窗任意点** → 画布直接跳转该区块（等同 Figma/Sketch minimap 跳转）；
    - **画布正常滚动** → 红矩形反向同步（迷你地图始终反映真实阅读位置）。
    - 长文(公众号常 3000+ 字)刚需，不藏二级菜单。
  - 浮窗缓存 debounce 200ms；编译 HTML 复用 `useCompiledPreview` 的 in-flight promise；iframe 限频刷新(150ms 节流)，离开滑块 400ms 销毁。
- 持久化：`canvasZoom` 写 EditorSettings + URL `?zoom=75`。缩放只改 CSS `transform: scale()`，不影响 `articleWidth` 与导出；预览/源码视图固定 100%。

#### 13.2.2 文件锁（File Lock）
- 位置：缩放器左侧 8px，🔓/🔒 切换。
- 状态：上锁→标题前 🔒 徽标、Tab 角标变红、编辑区 1% 红蒙层、所有写操作拦截。
- 拦截：键盘输入/粘贴/拖入/区块操作/标题/自动保存/主题/导入/历史/模板；放行：切视图/滚动/缩放/选中/复制纯文本；切锁前先 save 当前 dirty；解锁长按 0.8s 或密码(设置可选)。
- 数据：`useFileStore.openDocs[i].locked` + `Doc.lock?{locked,lockedAt,lockedBy}` 持久化 DB；后端 `upsertDoc` 拒绝 `lock.locked` 覆盖(HTTP 423 Locked)，前端解锁后握手。
- 快捷键 `Ctrl+Shift+L`；ActionRegistry 加 `lock/unlock/toggleLock`；锁住时 ⌘K 屏蔽所有写动作、放行解锁/切视图/复制。

## 18. 性能优化与资源占用优化（Msg 6 补齐）

> 目标：桌面端长文档(3000+ 字) + 上千素材时仍 60fps、内存不涨、启动 <2s。分层施策，先量后优。

### 18.1 启动与包体
- **代码分割**：`FileManager / SettingsDialog / ExportDialog / InsertAudioDialog / InsertVideoDialog / SvgEditor / LottiePreview` 全部 `React.lazy` 动态加载；首屏只打编辑器核心。
- **Tree-shake + 分析**：`vite-bundle-visualizer` 找 >50KB chunk 懒加载；`lottie-web` 按需引入（仅预览时出现），避免常驻。
- **延迟初始化**：诊断/更新检查/缩略图预生成等非关键初始化 `setImmediate` 延后；必要时 splash 占位。

### 18.2 文件管理器列表（必做）
- **虚拟化**：网格/列表用 `react-window`（定高）或 `react-virtuoso`（变高，如卡片图文混排），仅渲染可视区 ~20 项；素材上千不卡。
- **复用**：卡片/行 `React.memo` + 稳定 `key=id`（禁 index）+ `useCallback` 稳定回调；筛选/排序 state 下沉到子树，避免整页重渲。

### 18.3 编译/渲染管线（核心编辑器）
- `useCompiledPreview` 已缓存 in-flight promise（复用）；**编辑抖动去抖**：块变更 200ms 防抖触发重编译，鸟瞰 iframe 150ms 节流刷新。
- **增量编译**（v2.1）：仅重编变更块，未变块复用上次 HTML（块级 memo）。
- **精准订阅**：zustand 用选择器切片订阅，避免任一 store 变更触发全树重渲；`useFileStore`/`useDoc`/编辑器各自订阅必要字段，避免 context 上提导致的连锁重渲。

### 18.4 SQLite（better-sqlite3 后端）
- **WAL 模式**：`PRAGMA journal_mode=WAL`，读不阻塞写，并发稳。
- **预编译语句缓存**：所有查询走模块级 `prepare()` 缓存，避免每次重新 prepare。
- **索引**：`deletedAt / kind / lastOpenedAt / sha256 / (width,height) / tag` 建索引，列表/筛选/去重查询快。
- **历史裁剪**：`pushHistory` 按设置"历史快照保留数"自动 prune，防 DB 无限膨胀；软删行定期 `VACUUM`/清理。

### 18.5 内存与资源泄漏（必做）
- **卸载清理**：所有 `useEffect` 在 cleanup 移除事件监听、清 timer/`setInterval`、abort `AbortController`。
- **iframe/对象 URL**：模态关闭必须卸载预览 iframe + `URL.revokeObjectURL` 释放 blob；鸟瞰 iframe 悬停结束 400ms 销毁，限制同时存活 iframe 数。
- **缩略图**：落盘缓存（避免每次全尺寸进 DOM）；`<img loading="lazy">` + `IntersectionObserver` 懒加载网格图；blob URL 及时 revoke。
- **Lottie**：卸载时 `pause()` + `destroy()`。
- **监听器防累积**：IPC/全局监听注册即返回 cleanup，组件卸载必调。

### 18.6 诊断
- 设置"Web Vitals 浮窗"（§0.2 已有）+ dev 下 React Profiler；性能组提供"诊断日志级别"。
