交互不是截图，是真能点

微信公众号不允许执行 JavaScript，但允许 SVG 的 SMIL 动画。 InkForge 把交互做进 SVG：用 <animate> / <set> / <animateTransform> 描述状态变化，靠触摸与点击触发。

  • 点击 / 触摸双写触发，移动端稳定
  • fill="freeze" 保持终态，restart="never" 防止误触重置
  • 世界层 / 遭遇层 / 触发层编组，深层触发器不再被遮挡
  • 导出时逐条核对微信属性白名单

右侧是一个真实的 SMIL 交互——点一下试试。它没有任何 JavaScript。

<circle r="10" fill="none" stroke="#2C6BED">
  <animate attributeName="r"
    begin="ripple.click" dur="0.7s"
    from="10" to="130" fill="freeze"/>
</circle>

微信平台的坑，我们替你踩过了

公众号编辑器对 HTML 有严格限制。InkForge 在导出阶段逐条处理，而不是让你粘贴后反复试错。

完全不可用

position（absolute / fixed / relative 整行删除）、id 属性（含 SVG 内部）、animation / transition / @keyframes / @media、:hover / :active / 伪元素、全部 JavaScript。

SVG 动画属性白名单

只能动 x、y、width、height、cx、cy、opacity、d、points、stroke-width、stroke-dashoffset、fill 等；<set> 限 visibility，animateTransform 限 translate / scale / rotate / skew。

结构依赖

不使用 id / class / defs / embed，不用 href 与 url(#id) 做结构依赖，样式一律内联 style=""。

那些小怪癖

连续空格会被合并（改用不换行空格）；input 会被过滤（任务列表用 ☑ / ☐）；SVG 必须显式写 width / height，否则 iOS 上不显示。

两种方式，一分钟跑起来

普通用户

便携包，开箱即用

  1. 下载 inkforge-1.3.0.zip（162 MB，内置运行时）
  2. 解压到任意目录
  3. Windows 双击 scripts/inkforge.bat；macOS / Linux 执行 ./scripts/inkforge.sh
  4. 浏览器打开 http://localhost:5173
开发者

从源码启动

bash
git clone https://github.com/Yichenlemon/inkforge.git
cd inkforge
npm install
npm run dev

前端 :5173，后端 API :5177。需要 Node.js 18+。
